\begin{abstract}
Agentic inference---with multiple model calls per question---has shown promise across diverse reasoning tasks.
Yet it remains unclear whether gains come from orchestrated interactions (e.g., self-critique, multi-agent deliberation) or simply from spending more computation on independent samples.
We study this confound in biological question-answering by comparing four strategies at a matched budget of three model calls per question:
(A)~Direct single-call inference,
(B)~three independent solves with majority vote,
(C)~sequential solve$\to$critique$\to$revise, and
(D)~two independent scientists (researcher and skeptic) producing independent analyses, then adjudicated by a third call.
Across 30 main items per category in LAB-Bench (ProtocolQA, SeqQA, DbQA, LitQA2) and LABBench2 SeqQA2, we evaluate on two free-tier models (GPT-OSS and Gemma-4).

\section{Introduction}

Recent work has demonstrated that agentic approaches to reasoning---orchestrating multiple calls to language models with feedback loops, self-critique, or multi-agent discussion---can improve accuracy on complex scientific and mathematical tasks.
These gains have been attributed to the value of structured interaction and iterative refinement.
However, many studies confound two distinct sources of improvement:
(i)~the benefit of \emph{orchestrated interaction} (one agent learning from another's feedback, multi-agent deliberation, etc.) and
(ii)~the simple benefit of \emph{running the task multiple times} independently and aggregating results (e.g., majority vote or self-consistency).

This confound makes it difficult to understand what practitioners should optimize for when designing agentic systems under a fixed computational budget.
If the gains come primarily from independent sampling, then computational resources would be better spent on sampling diversity, model ensemble variety, or early stopping; if they come from structured interaction, then the cost of orchestration is justified.

\textbf{Research question:}
At a matched computational budget of three model calls per question, does structured agent interaction (self-critique, multi-agent deliberation) outperform independent sampling plus voting?

\textbf{Key contributions:}
\begin{enumerate}
  \item A controlled comparison of four inference strategies (Direct, Independent$\times$3, Critique, Multi-agent) on biological question-answering tasks, with all task IDs, prompts, and analyses frozen before evaluation.
  \item Evidence on the efficiency of orchestrated interaction: which mechanisms (self-revision, multi-agent adjudication) rescue errors and which introduce new mistakes?
  \item A replicable methodology using deterministic answer-equivalence rules, bootstrap confidence intervals, and task selection filters---no LLM judge, no multiple-comparison penalties on secondary contrasts.
\end{enumerate}

\section{Setup}

\subsection{Tasks and Datasets}

We selected \NOSS{} main items per category from two datasets:
\begin{itemize}
  \item \textbf{LAB-Bench} (v1, public Hugging Face release): four multiple-choice task categories from high-impact biology benchmarks: ProtocolQA (30 items), SeqQA (30 items), DbQA (30 items), LitQA2 (30 items).
  \item \textbf{LABBench2 SeqQA2} (commit c028ecdc): sequence analysis questions with injected input files, scored by official validators; 30 main items, excluding \texttt{restriction\_counts} (1.5 MB input) and items with invalid ground truth.
\end{itemize}

All prompts and task IDs were frozen before the main evaluation.
We excluded items with rendered prompts exceeding 6,000 characters (token budget) and applied a per-category deterministic shuffle (seed 20260925) to select pilot (2 items, decision-only), main (30 items), and reserve splits.

\subsection{Models and Decoding}

\begin{itemize}
  \item \textbf{Primary:} \texttt{gpt-oss-120b} (Cerebras, free tier) and \texttt{gemma-4-31b-it} (Google, free tier), evaluated on all 150 main items.
  \item \textbf{Auxiliary:} \texttt{gemini-3.5-flash-lite} on 75-item Flash-Lite subset.
  \item \textbf{Decoding:} temperature~0.6, per-(strategy, step) deterministic seed, completion cap at \texttt{max\_tokens} (set after pilot evaluation).
  \item \textbf{No prompt tuning:} identical instructions across models; GPT-OSS runs with \texttt{reasoning\_effort=low}.
\end{itemize}

Only \emph{visible} output is passed to subsequent calls; no hidden reasoning is exposed.
All calls use the same decoding parameters (seed, temperature).

\subsection{Scoring and Answer Equivalence}

No LLM judge is used.
Answers are parsed from a fixed format and matched via:
\begin{itemize}
  \item \textbf{Multiple choice:} letter match (A, B, C, \ldots).
  \item \textbf{Numeric:} within 1\% relative difference.
  \item \textbf{List/set:} order-insensitive set equality.
\end{itemize}

Missing or unparseable answers count as incorrect and do not vote.

\subsection{Pre-registration}

\textbf{Frozen before main evaluation:}
All task IDs, question prompts, answer instructions, model configurations, and primary analysis script (\texttt{src/analyze.py}).
The pre-registration document specifies:
\begin{itemize}
  \item Primary contrast: Multi vs.\ Independent$\times$3 (paired bootstrap 95\% CI, exact McNemar test).
  \item Secondary contrasts: Critique vs.\ Indep, Indep vs.\ Direct, Multi vs.\ Direct, Critique vs.\ Direct, Multi vs.\ Critique (exploratory, no multiple-comparison correction).
  \item Mechanism analyses: rescue rate P(correct | vote wrong), corruption rate P(wrong | vote right), self-revision flips, adjudicator performance on disagreement.
\end{itemize}

\subsection{Interpretation Template}

The data will support one of several narratives:

\textbf{TODO: Orchestrated interaction outperforms independent sampling (Multi $>$ Indep, Critique $>$ Indep).}
If true, structured agent feedback adds value beyond the raw compute budget.
Practical implication: invest in feedback loops, multi-agent deliberation, and self-critique.

\textbf{TODO: Independent sampling is sufficient; orchestration adds little or introduces noise.}
If true, multi-call budgets are better spent on diverse independent samples.
Practical implication: maximize sampling diversity and ensemble variety within budget.

\textbf{TODO: Mixed results: Critique helps on some tasks (or models); Multi helps on disagreement but corrupts otherwise.}
If true, orchestration is task- and model-dependent.
Practical implication: detect uncertainty (e.g., non-unanimity in Independent$\times$3) and selectively apply Critique or Multi.

\section{Limitations}

\begin{itemize}
  \item \textbf{No tool use or external retrieval.} DbQA and LitQA2 test parametric knowledge (e.g., recall of database conventions, literature facts); models cannot query databases or search the web. This ceiling may explain conservative absolute accuracies.
  \item \textbf{Free-tier models only.} Cerebras GPT-OSS and Google Gemma/Flash-Lite are publicly available but constrained. Results may not transfer to frontier models (e.g., OpenAI o1, Claude Opus).
  \item \textbf{Three-call budget.} We fix the budget at three calls per question. Larger budgets (e.g., ten calls) may shift the balance between strategies.
  \item \textbf{Statistical power.} $n = 150$ per model provides 80\% power to detect effects $\geq 0.15$ on an expected baseline of 0.50--0.70. Smaller effects may require more data.
  \item \textbf{Multiple-choice focus.} 150 of 175 questions are multiple choice (4--10 options), with 25 free-response (SeqQA2). Different answer formats may show different patterns.
  \item \textbf{Single prompt set.} One hand-crafted set of prompts for each strategy. Prompt variation may yield different conclusions.
\end{itemize}

\section{Conclusion}

This controlled study isolates the value of orchestrated agent interaction from the value of raw computational budget on biological question-answering.
We report point estimates and confidence intervals rather than relying on significance tests, pre-register all procedures, and use deterministic scoring.
The results provide guidance on when to allocate inference budget to multi-agent deliberation, self-critique, or independent sampling.

\section{Answer Equivalence and Tie-Break Rules}

\subsection{Multiple Choice}

For all LAB-Bench categories (ProtocolQA, SeqQA, DbQA, LitQA2):
Options are shuffled per question with a fixed seed.
An answer is parsed as the letter (A, B, C, \ldots) from the tag \texttt{<answer>...<\!/answer>}.
Two answers match if their letters are identical.

\subsection{Numeric (SeqQA2)}

For free-response numeric answers:
An answer is parsed as a number from the \texttt{<answer>} tag.
Two answers match if their relative difference is $\leq 1\%$: $|a - b| / \max(|a|, |b|) \leq 0.01$.

\subsection{Voting in Strategy B (Independent$\times$3)}

Given three answers and confidence scores:
\begin{enumerate}
  \item Cluster equivalent answers.
  \item If any cluster has $\geq 2$ members, return the first answer in the largest cluster.
  \item If all three are distinct, return the answer with highest confidence (earliest on tie).
  \item If any answer is missing or unparseable, it does not vote.
\end{enumerate}
